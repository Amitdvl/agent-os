# Reusable design kits

## Monochrome Workspace

[Open the kit](../skills/monochrome-workspace/assets/kit/README.md) · [Design rules](../skills/monochrome-workspace/assets/kit/DESIGN.md) · [Interactive specimen](../skills/monochrome-workspace/assets/kit/example.html)

A versioned, framework-free white-and-black design system for workspaces, editors, inspectors and dashboards. Its files and code work independently of Impeccable and agent skills. Copy the complete kit directory into a consuming project and link it from that repo's instructions. Adopted snapshots update deliberately.

Agents can discover it through the creator pack and `$monochrome-workspace`, or simply read the linked files. The skill is a thin entry point. Native Impeccable DESIGN.md plus schemaVersion 2 metadata are included as optional context. No provider, credentials, installation or new service is required.

Portable package provenance identifies the source repository/commit/stylesheet hash. Reference assets contain only generic specimen content. The kit does not package private video assets or prescribe the art direction of authored media.
