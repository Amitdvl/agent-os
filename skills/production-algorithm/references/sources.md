# Sources and adaptations

## Primary source

[Elon Musk explains his 5-step algorithm for running companies](https://www.youtube.com/watch?v=tdf3luOCNks), Startup Archive, published December 27, 2024, approximately 4:09. Musk speaks directly in the clip. It is an excerpt from Everyday Astronaut's Starbase tour, August 2021.

Approximate clip timestamps, checked against the public caption transcript retained with the original skill research:

| Time | Substance |
| --- | --- |
| 0:02–0:17 | Challenge requirements even when a smart person supplied them. |
| 0:20–1:05 | Try hard to remove parts or process steps; speculative future need can justify almost anything. |
| 1:09–1:33 | Associate constraints with a responsible person rather than a department. |
| 1:36–1:47 | Restate the first two stages and the roughly 10% add-back heuristic. |
| 1:48–2:24 | Simplify or optimize only after deletion. |
| 2:25–2:37 | Accelerate cycle time only after the preceding three stages. |
| 2:38–2:51 | Automate last; Musk describes having run the sequence backward. |
| 2:52–4:09 | The Model 3 glass-mat example illustrates questioning a bottleneck's purpose before investing further in its automation. |

The captions contain transcription errors. Use them for approximate navigation, not verbatim technical specifications. Musk's factory anecdote illustrates the method; it does not establish that an unrelated safety requirement can be removed.

[Startup Archive's companion article](https://www.startuparchive.org/p/elon-musk-explains-his-5-step-algorithm-for-running-companies-1eae) links the clip and full interview. Its numbered wording is explicitly attributed to Walter Isaacson's biography; do not present that wording as a verbatim video transcript.

## Supplementary application

[My Actual Social Media Strategy For 2027 - The Algorithm](https://www.youtube.com/watch?v=ZTSI3DDP_4A), Alex Hormozi, approximately 16:02, was the other source supplied when Production Algorithm was created.

That application contributed practical measurement questions, actual work time versus elapsed time, opportunity cost, and an accountable next-review cadence. These remain useful adaptations. Content-specific opinions about editing, posting volume, communication frequency, or conversion are not universal requirements and are not Musk's claims.

## Merge provenance and interpretation

- Engineer Algorithm originated as an explicit-only engineering review policy built around the same five stages, later packaged as a global skill. Its contributions are incident-proven guardrails, technical debt, blast radius, rollback, and rollout evidence.
- Production Algorithm was created from the two videos above and packaged as an explicit-only skill. Its contributions are outcome metrics, baselines, named owners, reversible trials, and review windows.
- This merge keeps Production Algorithm as the sole package and removes the standalone Engineer Algorithm package. The ordered method is grounded in Musk's direct account; measurement practices and technical safeguards are explicit operational adaptations.
- Interpreting the add-back heuristic as a learning signal rather than a numeric deletion target is a safety adaptation. It preserves the challenge to excessive caution without authorizing arbitrary deletion or weakening validated protections.
- The safety and authorization boundaries are agent operating constraints, not claims that Musk stated them in the clip.
