# Tool Routing

Use the selected pack manifests to choose an installed upstream CLI. Run a lightweight interface check when exact support matters. Prefer structured bounded reads, apply declared freshness rules, and require exact intent for writes. Never treat a binary's presence as authentication, inspect its private state, or improvise an alternate browser path that violates the selected profile.

Before operating a routed tool, read its managed SKILL.md and any declared routing.md. Load only references for tools needed by this task. Resolve missing required references before operating; never silently skip preflight, freshness, privacy, or verification requirements. Keep global guidance to capability routing and shared safeguards; maintain detailed recipes on demand in the managed tool folder.
