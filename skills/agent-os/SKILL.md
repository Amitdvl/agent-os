# Agent OS

Use the `agent-os` CLI for setup previews, status, diagnostics, updates, and safe uninstall previews. Default to preview mode. Never pass `--apply` unless the user explicitly requests deployment after reviewing the target paths and plan.

Agent OS manages only ledger-owned files and delimited instruction blocks. Missing external tools or authentication are human checkpoints, not permission to install or log in silently.

On an owner machine, Agent OS is also the privacy-preserving twin of reusable
local workflow changes. Do not complete a change to a portable local tool,
slash command, policy, routing rule, or setup contract without updating this
source checkout and running its validation, tests, diff check, and configured
twin audit. Record a specific exclusion for an intentionally machine-only item;
never copy credentials, sessions, archives, identity, or machine-specific paths.
