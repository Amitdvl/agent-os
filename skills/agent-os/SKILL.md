# Agent OS

Use the `agent-os` CLI for setup previews, status, diagnostics, updates, and safe uninstall previews. Default to preview mode. Never pass `--apply` unless the user explicitly requests deployment after reviewing the target paths and plan.

Agent OS manages only ledger-owned files and delimited instruction blocks. Missing external tools or authentication are human checkpoints, not permission to install or log in silently.
