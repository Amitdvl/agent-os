# Goal Prompt

Use this for long-running or verification-heavy work. Produce a paste-ready `/goal` prompt under 3,800 characters. State the outcome, authoritative context, measurable checks, environment, anti-cheating/safety constraints, progress evidence, cleanup, and final completion proof. Do not start goal mode unless the user explicitly asks to create the goal. Split genuinely independent phases into separate goals when one prompt cannot fit safely.
