# Sample Prompts

Examples only. Adapt them to agreed visual state; do not load this file by default or copy unrequested content.

## Product hero

```text
Purpose / format: premium product launch; vertical 4:5 intent
Primary request: a matte-black aluminum desk lamp
Subject / hierarchy: one lamp; silhouette first, material detail second
Composition / camera: slightly right of center, eye-level commercial view, negative space upper-left
Lighting / mood: soft directional key from the left, controlled edge separation
Materials / palette: matte anodized aluminum; charcoal, warm ivory accent
Text (verbatim): none
Avoid: props, logos, decorative text, mirror-like reflections
```

## Targeted room edit

```text
Primary image: Image 1, room photograph
Requested change: change only the white wall to deep forest green

MUTABLE:
- wall color and its local response to existing light

IMMUTABLE / LOCKED:
- person and identity, pose, furniture, artwork, room geometry
- camera, perspective, crop, composition, and all unmentioned elements

Integration: preserve existing light direction and shadow behavior on the changed wall.
Do not restyle, beautify, reposition, add, or remove anything else.
```

## Transparent asset

## Locked-state refinement

```text
Current locked state: product identity and geometry, camera, crop, composition, focal hierarchy.
Change only: shift the existing lighting temperature moderately warmer.
Preserve light direction, shadow structure, material roughness, palette relationships, and all locked state.
```
