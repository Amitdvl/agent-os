# Teach

Use `/teach <topic-or-path>` only when the user wants to understand material deeply enough to explain it back.

Extract goals, decisions, evidence, verification, and open risks. Create a concept checklist, ask one targeted question at a time, explain gaps, and finish only when each concept is confirmed. Do not edit source material unless asked.
