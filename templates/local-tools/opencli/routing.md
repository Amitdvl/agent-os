# OpenCLI adapters, profiles and browser bridge

Use OpenCLI for supported website adapters, external CLI hub access and Browser Bridge automation. Verify current version/help and adapter catalog before relying on examples; public adapters/local commands may not need bridge auth.

- Before browser-backed work run `opencli doctor`; list profiles when profile choice matters. Use the requested profile and never guess across personal/work profiles. Browser-backed commands require the supported bridge/daemon and a user-owned logged-in session.
- Prefer structured JSON/YAML. Cookie/intercept/UI adapters can operate on the logged-in session; posts, sends, purchases, uploads, account changes and any other remote/UI mutation need exact requested target/content/action. Never inspect cookies, browser storage, credential files or traces to recover access.
- Browser primitives use an explicit task session, for example `opencli browser SESSION state`; scope sessions to the task and close them when no longer needed. Inspect current state before action.
- For a **named X bookmark folder**, use the folder adapter before generic browser control or historical archives. List folders, match the requested name exactly ignoring case, then fetch its returned ID with a bounded limit. If the authenticated folder index fails, especially `bookmarkFoldersSlice` HTTP 404, use `opencli twitter bookmarks --limit 1000 -f json` corpus results instead. Explicitly label fallback evidence corpus-wide, never folder-attributed; do not manufacture folder IDs from cookies, storage or traces.
- For bridge setup, honor explicit in-scope site-access/extension/profile authorization when supplied. Otherwise extension installation/enabling and login remain human checkpoints; no portable blanket authorization is implied. Setup authority does not authorize unrelated sends, purchases, account mutations or private-data disclosure. Re-run doctor after authorized setup and confirm the chosen profile.
- Exit 69 indicates disconnected bridge, 75 timeout, 77 auth required in the reviewed interface. Diagnose with sanitized output, retry narrowly or adjust timeout only with evidence; do not bypass account protections or repeatedly replay writes.
