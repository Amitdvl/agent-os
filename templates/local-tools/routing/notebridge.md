# NoteBridge routing requirements

- NoteBridge: use `notebridge` for source-neutral local Wispr Flow and Apple Notes reads, bounded JSON-first inspection, explicit exports, guarded Apple changes, and guarded one-way mirroring. Before relying on it, run `command -v notebridge`, `notebridge --version`, `notebridge --help`, and `notebridge --format json doctor`. It has no credentials or network client. Treat provider data as private: do not expose note content, session material, or signed URLs unless the request requires it. Wispr access is read-only. For Apple operations, require the exact target/action and use stable `apple:` IDs only; mutations default to dry run and require `--apply --yes`. Mirrors require an exact Apple account/folder scope and reviewed dry run; they are one-way Wispr-to-Apple, track ownership/conflicts, and never delete Notes. Exports require an explicit destination; `--force` authorizes an intentional overwrite.
