# Instagram routing requirements

- Instagram: use `instagram-cli` for Instagram Direct inbox/search/read workflows, profile lookups, and explicit Instagram message actions. Run `command -v instagram-cli`, `instagram-cli --version`, and `instagram-cli auth whoami` before authenticated work. The CLI stores sessions under `~/.instagram-cli`; never expose or inspect session data. Treat `send`, `reply`, `unsend`, `auth logout`, `auth switch`, `config`, and `cleanup` as writes; treat `read --mark-seen` as a remote-state change and `read --download` as a local file write. Act only when the user's requested target and exact content/action are clear. If authentication is absent or expired, tell the user to run `instagram-cli auth login` locally; do not attempt interactive login on their behalf. Prefer `--output json`, bounded `--limit` values, and thread IDs from a fresh `inbox` response. Do not use browser automation or the Instagram website for Instagram tasks.
