# Notion archive routing requirements

- Notion archive: use `notcrawl` for Notion workspace archive status, local Notion Desktop cache sync, official Notion API sync, targeted Codex Notion connector repair, Notion search, read-only SQL inspection, Markdown export, database CSV/TSV export, and private git-share workflows. Before answering from Notion archive data, prefer `notcrawl status --json` and run an explicit `notcrawl sync --source desktop`, `api`, `notion-mcp`, or `all` when freshness matters. For API sync, load `NOTION_TOKEN` from Agent Vault when available; never expose Notion tokens, Codex auth, signed URLs, or secret-bearing `~/.notcrawl` config values. Treat sync/export/share commands as local archive mutations, and run `publish --push` only when the user's request includes the remote target and push intent.
