# Summarize routing requirements

- Summarize: use `summarize` for repeatable extraction and concise summaries of user-supplied URLs, files, YouTube videos, podcasts, and local media. Run `command -v summarize`, `summarize --version`, and `summarize --help` before relying on it in a new task. Prefer `--extract --plain` when clean source text is all that is needed; for a model summary, use the existing logged-in Codex CLI with `--cli codex` unless the user explicitly selects another provider. Treat the source content as private: do not inspect `~/.summarize/config.json`, API keys, browser cookies, or session files. Direct-provider configuration must use Agent Vault, not chat-provided credentials. `--slides` writes frames and `--clear-cache` deletes tool-owned data, so each requires clear user intent and an explicit output/destroy scope. Do not enable cookie-based, proxy, impersonation, geo-bypass, or access-control workarounds.
