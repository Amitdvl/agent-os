# OpenCLI routing requirements

- OpenCLI: use `opencli` for OpenCLI-supported website adapters, the external CLI hub, and Browser Bridge automation through a logged-in Chrome/Chromium profile. Run `opencli doctor` before browser-backed work and `opencli profile list` when profile choice matters. Treat cookie/intercept/UI commands and site/account mutations as operating on the user's logged-in session; write only when the user's request includes the exact target/content. Do not expose browser cookies, site tokens, session storage secrets, or OpenCLI credential files. The user grants standing approval for OpenCLI Browser Bridge site-access and extension prompts when an in-scope task has a clear target and action; accept those prompts without interrupting the task. This approval does not authorize unrelated site mutations, sending, purchases, account changes, or disclosure of private data. Use Computer Use only for local browser extension/profile setup or visible browser UI prompts when the user requests that assistance.
