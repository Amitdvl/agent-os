# Notion routing requirements

- Notion: use `notion` for Notion API auth checks, page/database search, page reads, block reads, and explicit page creation or text/markdown append workflows. The CLI auto-loads `NOTION_API_TOKEN`, `NOTION_API_VERSION`, and `NOTION_WORKSPACE_ID` from Agent Vault file `<agent-vault>/tools/notion.sops.env`; future runs must check that vault record before requesting Notion credentials or creating replacements. Run `notion auth status` before authenticated work. If the API returns `404 object_not_found`, the target page/database is probably not shared with the the configured Notion integration integration; report that the specific page/database needs sharing with the integration, or use the logged-in Notion UI through Browser Use/Computer Use when requested. Treat creates/appends as writes and act only when the user's request includes the target and content/action. Do not expose Notion tokens or decrypted Agent Vault files.
