# Freshness

- Before answering from a local communication or social archive, refresh through that tool's declared sync command unless the user requests no refresh or asks only about setup/status. Follow the selected contract's source selection, export and verification rules.
- For Discord data answers (messages, channels, DMs, guilds, reports or search), automatically run `discrawl sync --full` first, then query the archive; the same no-sync/setup exceptions apply. After a supported send, run another full sync before archive verification or answering. Load the Discrawl contract for its supported-command-only, exact channel/message and token-privacy safeguards.
- Check Notion archive status and select an explicit sync source when freshness matters. If refresh fails, distinguish stale-but-readable local data from unavailable current state.
