# Freshness

- Before answering from a local communication or social archive, refresh through that tool's declared sync command unless the user requests no refresh or asks only about setup/status.
- Use `wacrawl` for WhatsApp Desktop archive reads and `wacli` for live linked-device state or writes.
- Run a full Discrawl sync before answering from Discord data and again after a supported Discord write.
- Prefer Birdclaw's local archive for historical X analysis; use live transports only for current state or explicit writes.
- Check Notion archive status and select an explicit sync source when freshness matters.
- If refresh fails, distinguish stale-but-readable local data from unavailable current state.
