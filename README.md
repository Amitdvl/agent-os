# Agent OS

Agent OS is a private, opinionated distribution of Amit's local Codex and Claude Code workflow. It packages portable policy, commands, skills, capability manifests, and a guarded installer without packaging credentials, sessions, archives, or machine-specific state.

This repository is currently built and tested as an installable artifact only. It has not been deployed onto this Mac.

Start with [the quickstart](docs/quickstart.md). Architecture and audit evidence live in [docs/architecture.md](docs/architecture.md) and [docs/inventory.md](docs/inventory.md).
